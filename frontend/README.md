# Voiceflow AI Chatbot - Frontend

A React + Vite application featuring voice interaction, text-to-speech feedback, audio visualizers, and conversational memory.

---

## 🌟 Highlights

- **Interactive Voiceflow**: Real-time speech recognition (Push-to-Talk & Continuous modes) and browser Text-To-Speech.
- **Conversational Memory**: Chat sessions synced with the backend and stored in PostgreSQL.
- **Dynamic Waveform Visualizer**: Sound wave frequency bars and reactive glowing orb.
- **Model Switching**: Easily switch between Groq (Llama 3.3) and Hugging Face inference.
- **Glassmorphism Theme**: Futuristic dark mode with neon cyan and indigo accents.

---

## 🚀 Running the Frontend

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
